# RIAN-templates
Support ESP32, ESP8266
Use PCA9685

## Setup (Arduino IDE)
- Board Manager > esp32 by Espressif Systems > Install
- Install board driver if needed
- Library Manager > Adafruit PWM Servo Driver Library by Adafruit > Install All
- https://github.com/MyArduinoLib/Arduino-PS2X-ESP32 > Download ZIP > Extract to \Documents\Arduino\libraries
- Board: ESP32 Dev Module, Port: Select the correct COM port
